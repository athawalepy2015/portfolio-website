Reliable Clinical Decision Support using Retrieval-Augmented Generation

A research framework evaluating confidence calibration, evidence utilization, JSON reliability, and failure patterns in clinical question answering systems.

Project Overview

Evaluating reliability beyond accuracy.

This project studies whether clinical RAG systems are not only correct, but also reliable, calibrated, evidence-aware, and interpretable across multiple medical QA benchmarks.

Datasets

PubMedQA, MedQA, and MMLU-Med were used for cross-dataset clinical QA evaluation.

Pipeline

A fixed retrieval pipeline was used so the analysis could focus on generation-side reliability.

Models

Qwen and Mistral were evaluated for clinical answer generation and reliability behavior.

Analysis

Confidence calibration, evidence use, invalid JSON, and failure taxonomy were analyzed.

Why this matters

In clinical AI, accuracy alone is not enough. A model can produce a correct-looking answer while being overconfident, poorly calibrated, unsupported by evidence, or inconsistent across datasets.
